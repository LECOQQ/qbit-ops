# 🔒 Security policy

## Supported versions

Only the latest published release receives security fixes. If you run an
older version, upgrade first and check whether the problem persists.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: open the **Security** tab of this
repository, choose **Report a vulnerability**, and describe what you found.
Useful details are the affected version, the steps to reproduce, and the
impact you expect.

## What happens next

This project is maintained in spare time, so there is no guaranteed response
time. A report is read, acknowledged when it is understood, and assessed.
A confirmed vulnerability is fixed in a new release, and the report is
credited unless you prefer otherwise. The advisory is published once a fixed
version is available.
